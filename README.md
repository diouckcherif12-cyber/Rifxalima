# Rifxalima
Rif Xalima est un portail d’information sénégalais qui propose des actualités, des informations pratiques et des contenus utiles sur le Sénégal et l’Afrique. Le site couvre notamment les concours, formations, éducation, emploi, démarches et sujets d’actualité, avec une volonté de privilégier des informations vérifiées et accessibles.
